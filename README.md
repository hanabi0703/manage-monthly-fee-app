# 月謝管理アプリ

チームの月謝・会計を管理するスマホアプリです（React Native / Expo）。
データは端末内の SQLite に保存されます（1台のスマホで完結、他端末とは同期しません）。

## できること

- 日付 × メンバー名の一覧表で、誰がその日に月謝／ビジター料金を払ったか確認できる
- 支払い記録の入力(日付・名前・金額・区分)
- 月謝額の変更履歴を管理し、標準額との差額をメンバーごとの繰越金／未払金として自動計算
- メンバーページで、支払い履歴・繰越金額・未払金の有無を確認できる

## セットアップ

```bash
npm install
npx expo start
```

表示されたQRコードを Expo Go アプリ（iOS/Android）で読み取るか、
`i` で iOSシミュレータ、`a` でAndroidエミュレータ、`w` でWebプレビューを起動できます。

## 技術構成

- Expo (React Native) / TypeScript
- expo-router (ファイルベースのナビゲーション)
- expo-sqlite (端末内ローカルDB)
