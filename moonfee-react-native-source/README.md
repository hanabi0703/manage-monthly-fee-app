# MoonFee React Native UI Sample

月謝管理アプリ向けの、モダン・可愛い・手書き風デザインのReact Nativeサンプルです。

## 必要パッケージ

```bash
npx expo install react-native-svg
```

## 収録画面

- AccountingScreen
- PaymentInputScreen
- MembersScreen
- MemberDetailScreen
- SettingsScreen

## 補足
このソースはUIサンプルです。
DB・状態管理・ナビゲーション・永続化ロジックは既存アプリに合わせて接続してください。
